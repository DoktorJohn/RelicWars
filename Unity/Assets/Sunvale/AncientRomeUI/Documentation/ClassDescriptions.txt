AncientRomeUI C# Class Overview

This file lists the C# scripts included with AncientRomeUI and explains what they do in plain terms. 

Internal tools, custom inspector scripts, low-level tween helpers, and most demo-only data/enums are intentionally left out to simplify the file.

Core UI Utilities

CircularRaycastFilter - Makes a UI element receive clicks only inside a circular area. Useful for round buttons, medallions, and icon frames.
HorizontalRawImageTiler - Keeps a RawImage texture tiled horizontally as the element changes size.
VerticalRawImageTiler - Keeps a RawImage texture tiled vertically as the element changes size.
UIGlobalTextureTiling - Adds canvas-space tiling data to UI meshes so marble/noise textures can stay visually aligned across different UI elements.
ColumnPixelDensityScaler - Keeps column artwork at a consistent pixel density when a UI column is stretched wider.
SafeZonePanelScaler - Scales a panel so it fits inside a chosen safe-zone RectTransform.
SimpleButton - General-purpose animated UI button with hover, press, scale, sound, material tweening, UnityEvents, and C# events.
ToggleSoundCompanion - Adds hover and click sounds to a standard Unity Toggle.
TMPDropdownSoundCompanion - Adds hover, click, and value-change sounds to a TextMeshPro dropdown.
UISoundConfig - Reusable sound settings for UI interactions, including clip, volume, pitch, and pitch randomization.
SimpleSoundManager - Small shared audio helper used by the UI sound components.

Buttons and Tabs

LargeBuildingButton - Large building/action button with icon, frame, labels, animated hover/press feedback, and click events.
BuildingSlotButton - Compact building slot button with icon, empty-slot state, level label, radial progress fill, sounds, and click events.
CircularIconTabButton - Circular icon tab that swaps between normal and selected visuals.
RowHighlightButton - Simple row selection button with hover and selected-style color feedback.
OptionsTabButton - Horizontal tab button used by the options demo.
CarvedPressButton - Prominent text button with a pressed-in carved effect.
RPGSkillButton - RPG skill or hotbar button with icon shader controls, cooldown display, disabled/selected states, hover feedback, and ready highlights.
IconTextSidebarButton - Sidebar button with text, icon, animated side bars, and interaction feedback.
TextColorTabButton - Text tab button with animated frame color, text color, spacing, and selected indicators.
SkillTreeButton - Skill tree node button with locked, available, and unlocked visual states.
TableHeaderButton - Sortable table header that can report clicks on the header, up arrow, or down arrow.
FramedSpriteTabButton - Framed sprite tab with background swaps, label color, icon HSV changes, scale feedback, and selected state.

Graphics, Charts, and Visual Tools

DrapeGraphic - Custom UI graphic for drapes and banners with deformable mesh shape and wind animation.
SimpleFillBar - Simple material-driven fill bar for progress, meters, and decorative fills.
AnimatedHealthBarFill - Health/resource bar with main fill, ghost fill, damage/heal animation, flash effects, and optional number tweening.
GraphGridGraphic - Draws graph grid lines, outer edges, and axis notches as UI geometry.
GraphLineGraphic - Draws one or more graph lines with thick segments and point markers.
GraphAxisLabels - Creates and positions TextMeshPro labels around a graph grid.
GraphLineSeries - Data container for one line in a graph, including values, color, thickness, and scale bounds.
PieChartGenerator - Builds a pie chart from category values and colors.
PieChartCategoryLabel - Label view for a pie chart category, including name, count, percentage, and color.
PieChartSliceGraphic - Generated graphic used by PieChartGenerator for individual pie slices.
EllipticalHalfDonutChart - Builds an elliptical half-donut chart from category values.
EllipticalDonutSliceGraphic - Generated graphic used for individual half-donut slices.
EllipticalDonutBorderGraphic - Generated graphic used for half-donut chart borders.
SkillTreeConnectionBuilder - Builds the visual connection lines between SkillTreeNode objects.
SkillTreeNode - Stores skill tree node requirements, connection ports, layout insets, runtime state, and its linked SkillTreeButton.
SkillTreeConnectionGraphic - Draws a skill tree connection line, including Bezier or orthogonal paths, arrows, rounded corners, and dashed variants.
